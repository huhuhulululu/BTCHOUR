# 项目目标

> 本文件是**目标层级的唯一真相**。不要从 `huhuhulululu/kalshi`（15 分钟盘）抄日均美元阶段，也**不要抄它的坐等姿态**。
> 小时盘整条近 ATM 阶梯是工作盘（decisions **011**）。目标由用户设定；Agent 不发明 $10/$50/$200 天目标。

## 硬要求

在 Kalshi **BTC 小时盘**（系列 `KXBTCD`，下一个整点收）上，打出**人手那种 coupon clip**。

**提权：** 每小时一百多档（近 ATM `$600` / 32–42¢）是本仓库相对 15 分钟研究仓的操作优势。敏锐度和实际可操作性要压过那边的「没边就坐着」。空仓而阶梯活着 = 策略失败，不是盘口没机会。

**CMD（012）：** 最聪明、最灵活、产出最高。产出 = 真动量小时用满阶梯打出人手 clip，不是坐等，也不是噪声单灌水。

达成 ≠ 回放变绿。达成 = 纸盘 / `live_one` 实测走出人工金带子那种单。

**金带子的定义在 2026-09-03 改过一次（用户授权，ADR 017）。** 原定义是「挂进 + `t_clip`
兑现」。1557 小时 / 66.8 天的回测把兑现那一半推翻了：同一批 **354 张** coupon 成交，
**持到结算 −0.14¢（t=−0.05，公道），套上 10–50% 带 / −80% 止 / 8 分钟 scratch 之后
−3.75¢（t=−4.45）**，日历前后半都同号。赢家被截在 +10%、输家吃满止损，是不对称截断。
（本段数字按 ADR 034 修正后的载入口径；此前引的是 1544 小时 / 348 张 / −0.86¢ / −4.14¢，
差值 3.28¢ → 3.61¢，**判决不变**。)

**后来又有一个独立证据，比上面那组更硬**：整条 loop 在 1557 小时上跑端到端，
017 开是每张 **+2.18¢**、017 关是 **−1.05¢**——**同样的 137 笔进场**（017 只改出场，
进场门一个字没动），所以差额干净：**017 值每张 +3.23¢**（ADR 032 / 第 11 节）。
两条完全不同的代码路径给出 3.61¢ 和 3.23¢，互相印证。

**同时要说清楚的是：+2.18¢ 的 t 只有 0.56，前后半还打架。** 金带子这个定义现在是
**「不亏在出场上」**，不是「这样能赚钱」。整条阶梯上没有任何一条规则扛得住费用
（见回测第 10b 节：全阶梯都在自己费用门槛的 ±0.15pp 以内）。

| | 旧定义（作废） | **现行定义** |
|---|---|---|
| 进场 | 跟带子、$600 内、32–42¢ 活盘、rest 0.25 | **不变**（005 / 006 / 007 / 008 一字不动） |
| 兑现 | `t_clip` 10%–50% | **持到结算**。不 clip、不 trail、不 −80% 止、不 8 分钟 scratch、不 TWAP flatten |
| 判据 | 单张 ROI 好不好看 | **一批单的每张净值**。单张说明不了任何事 |

### 两张样板的实际结算（回测库核过，不是记忆）

| 单 | 事件结算 | 那一档 | NO 挂单持到结算 |
|---|---|---|---|
| `AUG2520` T78599 | 78513.03 | `no` | **赢，$1.00** |
| `AUG2608` T78299 | 78470.96 | `yes` | **输光** |

**`AUG2608` 那一张，clip 是对的**——持到结算它归零，`t_clip +18%` 救了这笔。这正是为什么
定义不能建在样板上：**十七张真单里挑出来的两张，方向相反**。改定义的依据是 354 张成交的
每张净值（外加端到端那 137 笔的 +3.23¢），不是 `AUG2608`。`AUG2520` 仍是金带子，且两种收尾都赢。

**新的失败信号**：拿单张 clip 的 ROI 当达成。空仓而近 ATM 阶梯活着（011）仍然是失败信号，
两条同时成立。

计分：`EV = p · b − (1 − p)`。~20% 是**过滤**，不是每笔保证。不要说每笔都赚 20%。

找不到下单点是策略问题，不是「盘口没机会」。188 档做成 1 笔噪声同理。不能实现就换策略，不要靠放宽门硬成交。

## 不是目标

| 不要 | 为什么 |
|---|---|
| 15 分钟盘 `KXBTC15M` / `KXETH15M` | 那是另一个仓库；小时盘主路径只做 `KXBTCD` |
| 把 15m「坐等」抄到小时盘 | 那边没阶梯；这边每小时一整条近 ATM 阶梯，操作权更高（011） |
| 回放 `flex_skip` / `flex_nowait` 变绿 | 对照，不是达成 |
| 整条 loop 切 live | 用户明确拒绝。`trading_active=true` 不是切 live |
| 把成交门放到 0.45 / 吃 taker / 放宽 p=0.30 | 对照过，更亏或吃瘪 |
| 看见 32–42¢ 就挂 / 孤零零停 25¢ | `AUG2911` 已证明蠢 |
| 日均美元阶段（抄 15m 仓库） | 用户没定 |

## 现行验证规格

- 默认 `BTCHOUR_MODE=paper`，playbook `flex`
- 实盘只允许 **`live_one`：每次 1 张 post-only**。已有 1 张 resting 不再挂第二张
- 亏了下一小时整小时不做 T；0 成交不叠 skip；clip 之后本小时不 hop
  （017 之后 coupon 按**结算**收尾，结算亏一样算「亏了」，`store.session_memory()` 和
  `replay_bars` 都按 settled 记，006 不受影响）
- 核盘：`python3 -m btchour board`，中文，纽约时间，只用表格

## 判据

- **进行中**：真 coupon 样本能复现人手规矩（跟带子、32–42¢ 活盘、rest 0.25、**持到结算**）
- **未达成**：回放 16h 0/0/0 或偶然 1 张小 clip（如 374 +0.0353）都不算达成
- **失败信号**：静/弱阳乱挂、垫档、吃 taker、整条切 live、为成交改门、**空仓而近 ATM 32–42¢ 阶梯活着还只报「没机会」**、**把赢的 coupon clip 走**
