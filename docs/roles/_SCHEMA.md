# 角色卡 schema（botdirectory 风格）

> 参考 [botdirectory.ai](https://botdirectory.ai) 与 `huhuhulululu/kalshi` 的 `docs/roles/`：
> **一角一卡、权责不重叠、主控只路由、不可逆动作要批准**。
> 每张卡必须能直接粘进 `Task` 的 `prompt=`，专员无需再猜职责。

本仓库是 **Kalshi BTC 小时盘**（`KXBTCD`），不是 15 分钟涨跌盘。编制比 `kalshi-15m` 瘦：没有 C1 / phase 网格 / `live_c1 --arm` / 日均美元阶段。

每张 `docs/roles/<ROLE>.md` 固定这些节：

| 节 | 含义 |
|---|---|
| **使命** | 一句话：这个角色存在是为了什么 |
| **独占所有权（权）** | 只有本角色可拍板 / 可写的事项 |
| **明确不负责（责边界）** | 遇到时交给谁；禁止越权 |
| **模型** | 默认 slug + 次选 + **为何高效且准确** |
| **触发** | 何时由 CMD 派发 |
| **必读 / 可写** | 路径白名单 |
| **输入 → 输出 → 完成定义** | 可验收 |
| **不可逆 / 须批准** | 对用户或 CMD 请示的动作 |
| **升级路径** | 卡住时找谁 |
| **派发 prompt** | 可粘贴的 Task 正文骨架 |

索引与模型花名册仍在 `docs/TEAM.md`（唯一入口）。
