## 一、止损线：太大就是漏

10b 量过整条阶梯的门槛：吃卖一持到结算，盈亏平衡所需的校准边就是 `100 × taker_fee(a)`。
实测下来**整条阶梯都在自己门槛的 ±0.15pp 以内**，便宜侧差 1.6–4.5pp。所以：

> **在这条阶梯上，任何报出 2pp 以上校准边的结果，先当成漏，再当成发现。**
> 先去翻标签、采样、成交口径里的时间轴，找不到问题再谈机制。

035 那次报出 **+19.95pp**。那不是边，是分桶标签里写了 `hour.settle`——要预测的东西本身。
**+20pp 是 bug 的自画像。** 这条止损线能把「兴奋」直接变成「排查」，
032 用了五轮才找到的东西，用它几分钟就能定位。

## 三、因此定下的规矩

1. **任何按分钟网格得到的表，发表前必须跟一张「全分辨率 + 去重 + 流动性分层」的对照表一起出现。**
   `research/study_density.py --audit` 就是这个对照的样板（030）。
2. **「我的挂单会不会被打到」用分钟极值是对的；「taker 付了多少」用它是错的。**
   成交判断只许用**严格晚于决策那一刻**的数据（032 / 033）。
3. **「取最小 / 取最大」是一种采样口径。** 每根 bar 约 78 个档位对，取最便宜的那个，
   挑的就是最不可能真实存在的那个——而且 `yes_bid(K1)` 与 `no_bid(K2)` 是**两个市场
   各自的 1 分钟收盘**，**不必同时存在过**。几何对照组（直接取夹住现货的两档、不看价格）
   在同样 500 小时里只挂得出 **4 对**，「最便宜」那版挂 484 对——差额全是挑出来的（038）。
4. **相对量的冷热过滤挡不住陈旧报价。** 深度虚值档可以有累计成交量、当前报价却是陈旧的。
   038 里挑中的对离现货**中位 $588**、成本低到 **$0.23**。要挡住得再加**距离**或**价差宽度**。
5. **冷热只有一份定义**：`hourly_lab.rung_reference_volume()` / `liquidity_tier()`，
   本小时中位档量的 ½ / 2×。结论落在冷档上的，不是可交易的结论（029）。
6. **去重要结构性的，不要事后补**：每小时只取一根决策 bar，比事后 dedup 更难出错（035）。
7. **Bonferroni 印在表头**，别留给读者自己算（035）。
8. **现货网格最后 20 秒不能读**：`/live_data` 的最后两个观测就是结算价本身，
   300/300 完全相等（034）。`hourly_lab.SETTLE_ECHO_SECONDS` 已经截断。
9. **别手抄生产的门和出场栈**——直接 import 它们跑。
   手抄的 `swing_t` 门放进 2168 笔，生产的门只放进 997 笔（031）。

## 四、留下来的三条（对照组）

它们能站住，恰恰因为上面那些检查没能把它们打倒：

- **017 成交的 coupon 持到结算**，不跑出场栈：同一批成交的持有 vs clip 对照，
  冷热同时作用于两边，两个半样本同号。出场栈扣钱这件事有**六次**独立复现。
- **019 TWAP 有效方差**：证据是 `(结算 − 现货)/σ` 的**实现标准差**，全程不碰盘口，
  所以采样偏差碰不到它。034 用 10 秒网格把它「推导但没验」的那一支也验了。
- **021 小时内波动季节性**：同上，量的是实现数据。

## 三点五、两种不是「采样口径」的失效（039 / 040）

前九种共同点是「汇总或计时口径在替你做判断」。第十、十一种不是，所以**九种模式全查一遍也抓不到它们**：

- **记账分支只错在一侧（039）。** `study_coupon` 把 50% 封顶按 `cap_price` 记，
  生产卖在 **bid**。封顶是最常见的出场、又是**赢家**那一支，于是这是单边削顶。
  修一行：出场栈从 −3.75¢ 变 **+0.282¢**。
  **配上错误的 t**：报的 t 检验「clip≠0」，而决策问的是「clip 比 hold 差」。
  配对差 **+3.226¢、t=0.93、CI 含零**，而且 hold 在 **72% 的单笔上是亏的**（中位 −4.667¢）。
  → **一个数字被复现五次 ≠ 被检验五次，如果五次用的是同一个错的对比。**
- **给错的函数盖章（040）。** `study_twap_tail.py` 九种模式逐条干净，
  却把结论盖在一个有单位 bug 的实现上——**它测的是接线的东西，不是写下来的东西**。
  而且这个 bug 让校准**看起来更好**，2pp 止损线也抓不到。
  → **验证公式前，先独立把公式算一遍，和实现对答案。**
- **审计放行了真缺陷（041）。** 同一个封顶 bug 也在 `study_candidates.py:161`。
  033 那轮我读到了，写下「它结算在限价上，不是观察到的极值」就过了——
  那句话对，但**生产不挂限价，它吃 bid**（`exits.py:145`）。
  → **study 声称复刻哪段生产逻辑，就逐行对那段生产代码；不要在 study 自己的逻辑里判它自洽。**
- **一个 bug 对不同玩法可以一个致命、一个无关。** 50% 封顶对 0.80 的偏强票要卖到 1.21，
  不可能触发；对 25¢ coupon 却是最常见的出场。**所以「同一个缺陷波及哪些结论」必须逐条量，不能推断。**
  修正后：coupon 的差 **t=0.93 不显著**（hold 只在 28% 单笔上赢），
  cushion 的差 **t=−2.05 仍显著**（clip 在 78% 单笔上更差）。**两种形状，不是一件事的五次复现。**
- **四条玩法逐条配对之后（042）：成立两条、不成立两条。**

  | 玩法 | 配对差 | t | |
  | --- | ---: | ---: | --- |
  | `swing_t` | −3.86¢ | **−2.62** | 成立 |
  | `cushion_hold` | −1.53¢ | **−2.05** | 成立 |
  | `impulse_wait`（coupon） | +3.23¢ | +0.93 | 不成立 |
  | `impulse_t` | −0.82¢ | −0.30 | 不成立 |

  **「出场栈在扣钱」不是这条阶梯的普遍事实，是四条里成立两条。**
  而且**唯一被接线的（coupon / 017）恰好是不成立的那条**，成立的两条都默认关着。
- **缺陷本身也要扫，不能推断。** 同一个「记我想要的价、不记盘口给的价」出现了**三处**
  （coupon 封顶、candidate 封顶、favourite 的 lock），**三处都只在赢家上触发、都朝同一边偏**。
  第三处是 grep 出来的，不是想出来的——线索是 `lock_on_book 20%` 打出正好 **+0.000¢**。
  → **可疑的整数值要停下来问为什么。**
- **别从子样本外推。** 我在 300 小时上看到 `swing_t` t=−1.66 就说「不显著」；
  全带子上它是 **t=−2.62、显著**。子样本可以用来找线索，不能用来下判决。

## 四点五、被关掉的最后一族，也是差得最少的一族（036）

**关掉方向性各族不等于关掉这条阶梯。** 10b 的费用门槛只管方向性的赌；
它管不到阶梯的**自洽性**，也管不到 **maker 门槛为 0.0pp** 这件事。所以 035 之后还有活干。

- 阶梯**是自洽的**：350 万个档位对里，和为一违例 0 个，最便宜的一对中位 **$1.0107**。
- 但同一对**挂**着只要 **$0.9900**，99.78% 的 bar 都在 $1 以内——**有价差可赚**。
- **腿风险几乎正好吃掉它**：补齐 15.9%（+5.00¢）、裸腿 51.0%（补齐后 −1.33¢），
  合计 **+0.119¢、t=0.45**。价差覆盖了腿风险的 **85%**。
- **关掉的理由是「这个数是上界」**：成交口径用的是触碰，027 说触碰是 maker 的上界。
  上界都只有 t=0.45。

**最有用的一句**：市场把价差定在了正好补偿腿风险的位置。
这是本仓库第一次**说清楚为什么没有边**，而不是又一次「测不出边」。

## 五、结论本身

**66.8 天里，这条阶梯上没有任何一条能扛住费用的 taker 或 maker 规则。**
端到端跑满 1557 小时，按正确口径每张 **+2.18¢、t=0.56**、前后半打架。
本轮唯一可量的 EV 提升是**减法的**（少付出场栈）。
maker 的费用门槛是 0.0pp，这是唯一有过机会的路，015 / 027 用逆向选择关掉了它。
