### 014 停 `live_one`（安全停机补丁）；停机期间跌侧挂门 |impulse| ≥ $100

- 日期: 2026-08-30
- 状态: accepted
- 定性: **安全停机补丁**。不是金带改进，不是 005 的可采纳修订。006 / 007 / 008 一字不动。
- 背景: 用户 07:42 EDT「如果没有新的改善或变化，就不要做了」；07:48 EDT「所有角色都参与」。今天 382–388 七张真挂，挂时动量 −15 到 −0.2，无一张 NO |impulse| ≥ $100，无一张是金带子那种 dump。live_one 17 张、成交 14 张净 +0.0677 是噪声。引擎事实：live_one 由交易所成交直接 promote，005 的同向 $100 成交门只对纸盘 rest 生效。
- 全员: LEARN 可采纳候选、不是达成。ADV 攻得倒、降级为停机补丁。ARCH 推荐 D。RISK 黄、现在停 live。MON 无滞留。ENG 102 绿。QA 可合并。DOC 对齐 plays.md。RPT=CMD。
- 决策:
  - `live_one` 默认 **False**。真单通道保留（004 不撤），但默认不往交易所送。
  - 停机期间跌侧挂门：挂 NO 要 `impulse < 0` **且** `|impulse| ≥ $100`，且 32–42¢ 看见。涨跌同门。YES 仍 28–42¢，不回退「不挂 YES」。005 原文不改；重开 live 时必须重新论证 $100。
  - live_one 真单淡化即撤（`wait_fade`）；纸盘淡了仍坐。该分支在 `live_one=False` 下不可达，回放不算验证。

- 不因此回退: 成交门 0.45、吃 taker、放宽 p=0.30、整条 loop 切 live、「不挂 YES」、看见 32–42¢ 就挂。
- 理由: 送的是同型噪声单。先关真钱通道。

### 016 `cushion_hold` / `edge` playbook（候选，**未通过样本外，不接线**）

- 日期: 2026-09-03
- 状态: **rejected-pending-data**（代码已并入，默认 **关**；留作 `sweep` 对照）
- 背景: 用户要求借鉴 `huhuhulululu/kalshi`（只读，未改动）提升 EV。那边 48 个 phase 里唯一
  的跨币种失效点是 phase1 的「偏强 0.85–0.95 被低估 1.5–2pp」。移植的不是它的参数，是机制：
  现货已把行权价甩开 ≥N 个**剩余波动** σ（`sigma_cushion`，`lock_hold` 用的同一函数），而
  该侧卖一还在 0.70–0.90 → 吃卖一，持到结算。
- 证据: `catalog/research/hourly-backtest-2026-09-03.md` 第 4 节。全样本 n=1612、**+0.53¢、
  t=0.62、CI [−1.15, +2.21]**；日历三分之一 −0.08 / −0.62 / +2.28；**前后两半符号相反**
  （σ2.0–2.5×0.80–0.90：前半 −3.27pp、后半 +5.60pp）；**+1¢ 滑点即翻负**（−0.42¢）。
  九条预注册候选里唯二过 Bonferroni 的是两条负对照（coupon taker −2.20¢ t=−4.05、
  cheap 0.18–0.30 −3.30¢ t=−5.48）。
- **模型修正后逐次重测（同日）**: 上面那组数字用的是修正前的 `digital_prob`。

  | 模型 | n | 每张净 | t | 日历三分之一 |
  | --- | ---: | ---: | ---: | --- |
  | 修正前 | 1612 | +0.53¢ | 0.62 | −0.08 / −0.62 / +2.28 |
  | +019（TWAP 方差） | 1665 | +0.47¢ | 0.56 | −0.06 / −0.36 / +1.83 |
  | +019+021（再加小时内季节性） | 1879 | **+0.07¢** | **0.09** | −0.02 / −1.55 / +1.78 |

  **模型越准，这条「边」越小。** 这本身就是判决：所谓「盘口没跟上模型」里，相当一部分
  是**模型自己错**，不是盘口错。判决不变，而且比之前更硬。
- 决策:
  - **不接线。** `BTCHOUR_CUSHION_HOLD` 默认 `0`；`--playbook edge` 与 sweep 的
    `edge` / `flex_cushion` 只作对照，地位等同 `flex_cheap` / `flex_nowait`。
  - 首次看见它是在 18 小时→18 天的样本上（+2.7¢ t=2.2），样本一长就塌。**小样本变绿不是达成**
    在进场规则上同样成立。
  - 重开条件：样本翻倍（≥130 天）后按 `research/study_rule.py` 原脚本重测，两个日历半样本
    同号且 +1¢ 滑点后仍为正，才允许再提。
  - **重开条件不可回填（022）**：Kalshi 只保留约 66 天的已结算市场记录，更早的事件连
    `result` 和 `expiration_value` 都没有。130 天只能**往前攒**——从 2026-09-03 起每天跑
    `research/pull_hourly.py`，约 65 天后才够。中断超过 66 天，那段永久丢失。
- 结构保证（这条 play 即使被打开也不碰任何冻结门）: 卖一下限 **0.70**，所以 008 的
  「不吃 0.45–0.70 taker」结构上不可达；不挂单，所以不碰 005；不做 T，所以不碰 006 / 007。
- 不因此回退: 0.45 成交门、吃 taker、p=0.30、整条 loop 切 live、「看见 32–42¢ 就挂」。

### 017 出场栈是本仓库当前最大的可量漏洞

- 日期: 2026-09-03
- 状态: **accepted**（用户 2026-09-03「授权你」）。`BTCHOUR_IMPULSE_WAIT_HOLD` 默认 **1**；005 的进场原文一字不动，这是**出场**改动
- 背景: 016 的回测顺带把「同一批进场，持有 vs 出场栈」量了出来。两组互不相干的进场给出同一
  答案，方向一致、都显著。
- 证据（`catalog/research/hourly-backtest-2026-09-03.md` 第 2、3 节）:

  | 同一批进场 | 持到结算 | 套现行出场栈 | 差 |
  | --- | ---: | ---: | ---: |
  | coupon 成交 348 张 | −0.86¢ (t=−0.33) | **−4.14¢ (t=−4.99)** | **−3.28¢** |
  | cushion 进场 1612 张 | +0.53¢ (t=+0.62) | **−1.61¢ (t=−4.73)** | **−2.13¢** |

  coupon 那组在日历两半都显著（早 −7.96¢ t=−4.60 / 晚 −3.31¢ t=−3.06）。15 分钟仓在另一个
  合约上同向（phase4 G1 十一条出场全负；phase12b 止盈在每个价带都比持有差 1.3–2.7¢）。
- 机制: 不对称截断。赢家被 `t_clip` 截在 +10%（上限 50% 很少摸到），输家吃满 −80% `t_wait_stop`
  或 8 分钟 `t_scratch`。这不是阈值松紧，调 10%/50%/−80% 都改不掉符号。
- 决策:
  - 成交的 coupon 按**结算**了结：不 `t_clip`、不 `t_trail`、不 `t_wait_stop`、不 `t_scratch`、
    不 `lock_on_book`（25¢ 上的 20% 锁就是 `t_clip` 换名字）、不 TWAP flatten。
  - 默认 `BTCHOUR_IMPULSE_WAIT_HOLD=1`。设 `0` 恢复旧栈，作为 sweep 的 `flex_clipstack` 对照。
  - **005 / 006 / 007 / 008 原文不动。** 挂单门、skip 小时、不 hop、不吃 taker 全部照旧；
    改的只有成交之后怎么收尾。
  - `cushion_hold` 与 `lock_*` 已经由 `strategy.is_settle_play()` 结构性豁免出场栈。
  - **006 不受影响**: 结算亏一样算「亏了」。`store.session_memory()` 本来就读 settled；
    `replay_bars` 的 settle 分支同步补上 `remember_session_exit`，否则 skip 小时会随着
    clip 栈一起悄悄失效。
- 后果: GOALS 的「金带子」定义已按本条重写（用户同一次授权）。兑现那一半从 `t_clip 10%–50%`
  改成**持到结算**；判据从单张 ROI 改成一批单的每张净值。
- **014 的重开条件 ① 随之改写**（不是放宽，是换成现行定义，否则它永远不可达）: 原文要求
  「纸盘出现 AUG2608 型（挂时同向 |impulse| ≥ $100、带内、真成交、**10–50% clip**）」。
  017 之后没有 clip 这一步，① 改成「挂时同向 |impulse| ≥ $100、带内、真成交、**持到结算**」。
  014 的 ② ③ 与「经用户批准」原文不动，`live_one` **仍然默认关**。
- **校正（写进 ADR 以免再被引用错）**: 起草时曾写「`AUG2608` 那张 NO 结算是 $1.00，clip 只拿了
  一小块」。**这是错的。** 回测库核过：`KXBTCD-26AUG2608` 结算 78470.96，`T78299.99` 判 `yes`，
  那张 NO **持到结算归零**——clip 救了这一笔。`AUG2520` 反过来：结算 78513.03，`T78599.99`
  判 `no`，NO 持到结算赢满。两张真单方向相反，这正是本条的依据必须是 348 张成交的每张净值、
  而不是任何一张样板的原因。
- 不因此回退: 0.45 成交门、吃 taker、p=0.30、整条 loop 切 live、「看见 32–42¢ 就挂」。

  >30 分钟是 1.05、10–30 分钟 0.96、**最后 10 分钟 0.82**。漂移可忽略（均值 +0.014σ）。
- 事实: `KXBTCD` 结算 = 最后 60 个 BRTI 报价的**简单平均**（`catalog/rules/settlement.md`），
  不是最后一跳。对布朗路径取尾部均值，方差小于取端点。
- 旧实现是**反的**: `seconds <= 60` 时把 tau **抬到** 60 秒地板，等于宣称「还剩 10 秒时仍有
  整整一分钟波动没走完」。实际此时均值窗口已经印掉大半。
- 决策: `model.twap_variance_seconds(τ, T=60)` 给有效方差时间，`digital_prob` 与
  `sigma_cushion` 共用（两者必须描述同一个分布）：

  ```
  τ ≥ T :  τ − 2T/3          # 大 τ 时 ≈ τ；τ=60s 时 = 20s
  τ < T :  τ³ / (3T²)        # 已经在均值窗口内；两支在 τ=T 相接
  ```

  推导: 结算 = (1/T)∫ 路径 over [τ−T, τ]，Var = (1/T²)∬min(s,t)。
- 证据: 1544 小时 / 15.2 万条观测，Brier 在**每一个**时间桶都变好——全样本
  0.08727 → **0.08716**，10–30 分钟 0.07778 → 0.07761，**最后 10 分钟 0.05288 → 0.05231**。
- 幅度诚实说: 全样本 Brier 只好 0.13%，最后十分钟好 1.1%。**这是把模型算对，不是找到边。**
  它让每一道用 `model_p` 的门（`swing_min_gap`、`invalidate_p`、`lock_min_p`、cushion）更准，
  不产生新的进场。
- 局限: `τ < T` 那一支是**推导的、未被样本验证**——回测样本从 τ=120s 起。它主要影响
  `flatten_seconds` 附近的判断，那一段没有历史可核。
- 后果: 016 的数字按新模型重测（n=1665、+0.47¢、t=0.56），**判决不变**。

### 021 小时内波动季节性：trailing 估计器按位置系统性偏差

- 日期: 2026-09-03
- 状态: accepted（**修正**，不是新的边）
- 背景: 019 接线后残差仍有结构——`(结算 − 现货)/σ_模型` 的 sd 按距收盘分桶是
  45–60m **1.072** / 30–45m 1.059 / 20–30m 1.025 / 10–20m 0.951 / 5–10m **0.880**。
  模型在小时早段偏窄、晚段偏宽，不是随机噪声。
- 机制: BTC 在小时内不是匀速走的。每分钟 |对数收益| 中位从第 5 分钟的 **1.61bp** 降到
  第 55 分钟的 **1.21bp**。trailing-15m 估计器在第 5 分钟量的主要是**上一小时的尾部低波动**、
  却用到本小时的高波动开盘段（跑冷）；在第 50 分钟量的是中段高波动、用到收盘前的静段（跑热）。
- 决策: `model.variance_seconds(seconds, minute)` = 019 的 TWAP 有效方差时间 × 按小时内
  profile 重整的比例。权重是每 10 分钟一块的 `E[r²]`（均值归一）：

  ```
  HOUR_VARIANCE_WEIGHTS = (1.14, 1.03, 0.94, 1.16, 0.94, 0.78)
  ```

  `minute=None` 时比例恒为 1.0——**任何拿不到小时内位置的调用点行为完全不变**。
  `strategy.hour_minute()` 只对 `is_hourly_window` 为真的合约给位置，15m / 日盘 / 周盘
  一律走原来的平坦路径。
- 口径纪律: 权重**只在日历前半**（772 小时）估计，**在后半验证**。
  - 样本外 Brier **0.08829 → 0.08799**（可交易切片 ≥180s 同为 0.08799）
  - 样本外 realised/model sd 的平均 |误差| **0.053 → 0.038**
  - **60 点逐分钟 profile 的样本外分数是 0.08800——和 6 块的 0.08799 一样。**
    形状是结构性的，不是拟合出来的；六个数就是诚实的分辨率。
- 幅度诚实说: 0.34%。**这不是边，是把模型算对。** 增益集中在最后十分钟，而本仓库
  `swing_min_seconds=180` / `flatten_seconds=40`，本来就不在那一段交易。它的价值是让每一道
  读 `model_p` 的门（`swing_min_gap`、`invalidate_p`、`lock_min_p`）少一点系统性偏差。
- 副产物（比修正本身更重要）: 016 的 cushion 信号随模型变准而**塌向零**

### 036 阶梯自洽、两腿挂单被腿风险吃掉——费用门槛为 0 的那一族也关了

- 日期: 2026-09-04
- 状态: accepted（事实登记；**本轮唯一一个差得最少的族**）
- 起因: 我在 035 之后停早了。**关掉方向性各族 ≠ 关掉这条阶梯**——
  10b 的门槛 `100 × taker_fee(ask)` 只管「赌 BTC 往哪走」。它管不到两件事：
  188 个档位在**同一瞬间**是否自洽；以及 **maker 的门槛是 0.0pp**。

**A. 阶梯是自洽的**（`research/study_ladder_arb.py`）。
`K1 < K2` 时买 `YES(K1) + NO(K2)` **任何情况下都至少付 $1**，`K1 < S ≤ K2` 时付 $2；
所以成本 < $1 就是锁死的利润。同理单档 `yes_ask(K) + no_ask(K) < 1`。
**350 万个有序档位对里**：和为一违例 **0 个**；单调性违例只有个位数、每张 +0.14 到 +0.26¢。
每根 bar 最便宜的那一对**中位数 $1.0107**——差 1.07¢，几乎正好是两个半价差加两次费。

**B. 但同一对「挂」着只要 $0.9900**，99.78% 的 bar 都在 $1 以内。
这不是套利：`yes_bid(K1) < yes_ask(K2)` 只是说**价差比两档之间的密度差更宽**。
吃这个价差叫**做市**，而 015 / 027 关掉的是**方向性**单腿 coupon——
**一对补齐的腿没有方向可供逆向选择**。真正的风险是**腿风险**：只成交一条腿就裸了。

**C. 腿风险几乎正好吃掉价差**（`research/study_two_leg_maker.py`，1556 小时、
只在非冷档里**先筛后挑**、挂单只能从 t+1 起被打到）:

| | 占比 | 每张 |
| --- | ---: | ---: |
| 两腿都成交 → 锁死 | 15.9% | **+5.000¢**（t=+3.74） |
| 只成交一腿 → **立刻吃 taker 补齐** | 51.0% | −1.329¢（t=−4.71） |
| 一腿都没成交 | 33.1% | 0 |
| **全部挂出去的对** | | **+0.119¢、t=+0.45** |

  前后半 **+0.22 / +0.02**；裸着拿到结算更差（−0.474¢、t=−1.58）。
  账算得很干净：`0.159 × 5.00 = 0.795` 的收，对上 `0.510 × 1.329 = 0.678` 的腿成本。
  **价差覆盖了它本来要补偿的腿风险的 85%，差的就是那 15%。**

- **判决：关。而且理由不是「测出来是零」，是「+0.119¢ 本身是上界」。**
  本研究的成交口径是**触碰**（`ask_low ≤ 我的挂价`），027 已经确认触碰是 maker 成交的**上界**——
  真实挂单排在队尾。口径收紧只会让 15.9% 的补齐率往下掉，51% 的裸腿率不会掉。
  **上界都只有 t=0.45，真值在零以下。**
- **两条一般性收获**:
  1. **市场把价差定在了正好补偿腿风险的位置。** 这是本轮第一次不是「测不出边」，
     而是**说清楚了为什么没有边**——1.00¢ 的价差不是随便宽的，它就是腿风险的价格。
  2. **029 的陷阱在这一族最凶**：不先筛流动性、直接在全阶梯上挑最便宜的一对，
     300 小时里 **300 对有 299 对落在冷档上**，「补齐收益」中位数被抬到 **+41¢**。
     先筛后挑之后中位数是 **+1.00¢**。**「先筛再挑」和「先挑再筛」是两个不同的实验。**
- 又一次自我更正（第八次，发表前抓住）: 补齐那条腿最初是从**挂单之后**的第一根 bar 找价，
  而不是从**成交之后**——等于在第一条腿成交之前就去补第二条腿。
  值 **+0.42¢** 的纯漏（+0.564¢ → +0.149¢）。和 032 是同一个时间轴对折。
- 不因此改门: 没有新玩法接线。017 / 019 / 021 照旧。

### 040 `seasonal_scale` 单位写错，034 验证的是「019 × 这个 bug」；τ<T 那一支仍未验证

```python
remaining = sum(hour_variance_weight(m) for m in range(start, start + max(1, round(flat_minutes))))
```

| ---: | ---: | --- |
