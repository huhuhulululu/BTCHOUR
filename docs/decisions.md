### 011 小时盘阶梯操作权高于 15 分钟研究仓

- 日期: 2026-08-29
- 状态: accepted
- 背景: 用户 13:47 EDT：每个小时那么多盘，不可能机会那么少。本仓库敏锐度 / 实际操作可能性远比另外的仓库（`huhuhulululu/kalshi`，15 分钟盘，结论偏无波动率溢价、坐等）更厉害，要把这个更加提权重视。本小时 `AUG2914` 快照 **188** 档，只做成 1 笔噪声 live（375）。
- 决策:
  - 小时盘整条近 ATM 阶梯（距离 **$600**，活盘 **32–42¢**）是**工作盘**，不是 15 分钟仓那种「没边就坐着」。
  - **空仓而近 ATM 阶梯活着 = 策略失败**，不是「没机会」。
  - CMD 心跳必须报：整点档数 / `$600` 内 / 32–42¢ 活档。不能只报空仓。
  - 操作强度优先于 15 分钟研究姿态。不把 15m 坐等抄过来。
  - 本小时已 clip **不 hop**（007）。用满阶梯的提案给下一小时。
  - **不因此回退**：看见 32–42¢ 就挂、成交门 0.45、吃 taker、放宽 `p=0.30`、整条 loop 切 live。
- 理由: 一百多档近 ATM 阶梯是本仓库相对 15m 仓的优势。机会少是策略没用上阶梯。

### 014 停 `live_one`（安全停机补丁）；停机期间跌侧挂门 |impulse| ≥ $100

- 日期: 2026-08-30
- 状态: accepted
- 定性: **安全停机补丁**。不是金带改进，不是 005 的可采纳修订。006 / 007 / 008 一字不动。
- 背景: 用户 07:42 EDT「如果没有新的改善或变化，就不要做了」；07:48 EDT「所有角色都参与」。今天 382–388 七张真挂，挂时动量 −15 到 −0.2，无一张 NO |impulse| ≥ $100，无一张是金带子那种 dump。live_one 17 张、成交 14 张净 +0.0677 是噪声。引擎事实：live_one 由交易所成交直接 promote，005 的同向 $100 成交门只对纸盘 rest 生效。
- 全员: LEARN 可采纳候选、不是达成。ADV 攻得倒、降级为停机补丁。ARCH 推荐 D。RISK 黄、现在停 live。MON 无滞留。ENG 102 绿。QA 可合并。DOC 对齐 plays.md。RPT=CMD。
- 决策:
  - `live_one` 默认 **False**。真单通道保留（004 不撤），但默认不往交易所送。
  - 停机期间跌侧挂门：挂 NO 要 `impulse < 0` **且** `|impulse| ≥ $100`，且 32–42¢ 看见。涨跌同门。YES 仍 28–42¢，不回退「不挂 YES」。005 原文不改；重开 live 时必须重新论证 $100。
  - live_one 真单淡化即撤（`wait_fade`）；纸盘淡了仍坐。该分支在 `live_one=False` 下不可达，回放不算验证。

- 不因此回退: 成交门 0.45、吃 taker、放宽 p=0.30、整条 loop 切 live、「不挂 YES」、看见 32–42¢ 就挂。
- 理由: 送的是同型噪声单。先关真钱通道。

### 016 先修计量：回放成交、结算模型、研究框架（提案）

- 日期: 2026-09-18
- 状态: **proposed**（代码里已落的只有计量部分，见下「已生效」）

  - 新增 `btchour/research/`：合成盘、自举区间、t 值、样本外切分、真 tape 归档。`python3 -m btchour research …`。
- 决策（提案，等用户）:

### 017 D 作废：模型跑不赢市场中价（真 tape 判定）

- 日期: 2026-09-18
- 状态: accepted（判定）/ proposed（波动率地板）
- 背景: 016 的阻塞解除，出网白名单放行 `external-api.kalshi.com`。归档 **92 小时**真实
  tape（`26SEP1414`–`26SEP1809`，48568 个近 ATM 读数），跑 016 自己定的决定性检验。
- 判定:
  - 模型 Brier **0.11519**，市场中价 **0.10319**。按小时聚类自举，差 **+0.01199**，
    95% 区间 **[+0.00844, +0.01551]**，不跨 0。
  - 门真正开火的地方（分歧 ≥5¢，33252 个读数）差距更大：**+0.01702**，区间
    **[+0.01216, +0.02150]**。
  - 四个分歧桶**全部**中价更准。24 小时子样本同结论同量级，不是时段巧合。
  - 波动率扫了 9 档（地板 0.20–0.55、realized、固定值、×0.8/×1.3）。**没有一档让模型
    赢**，最好的一档（realized 无地板）差 +0.00077，只是逼近打平。
  - 样本外：`swing` 92 小时两段都亏（−10.49 / −9.65，合计 −20.14 / 37 笔）。24 小时窗口
    里那个 t=3.18 是窗口挑出来的。默认 `flex` 92 小时动手 1 次。
  - 因此 **016 的 D（把「单笔 EV ≥ 20%」改成「小正 EV × 笔数 + 风险上限」）作废**。它的
    前置是模型 Brier 跑赢中价，该前置被真数据证否 —— 是证否，不是「还没测够」。
  - 连带作废: 任何以「`digital_prob` 看见了盘口没看见的东西」为前提的 taker 入场规则。
    门开火的那 75% 读数里，开的是模型误差。
- 已生效（计量，不是门）:
  - `.gitignore` 改 `data/*` + `!data/archive/`，tape 归档进版本库。容器是临时的，归档不
    进 git 就等于每个会话从零开始 —— 这是本仓库从来没攒够样本的直接原因。
  - `KalshiClient._request`: GET 撞 429/5xx 指数退避重试（认 `Retry-After`），请求间隔
    下限 60ms。签名 POST 不重试（重发订单会开重仓）。`tests/test_kalshi_retry.py`。
- 提案（等用户批，本线程不自行改默认）:
  - `annual_vol` 地板 0.55 → realized 不设地板（或地板 0.20）。依据见
    `catalog/research/findings.md` 第 2 节：地板把 p 拽向 0.5，中价桶 0.9–1.0 真实频率
    0.979、中价报 0.958、模型报 0.865。
  - **这条会动门**: 分歧 ≥5¢ 的开火率 75.3% → 20.0%，engine 出手会少很多。按 016 的规矩
    走提案。
  - 改完模型也只是**打平**中价。修它是为了不再自伤，不是为了拿优势。
- 不因此回退: 成交门 0.45、吃 taker、放宽 p=0.30、整条 loop 切 live、「不挂 YES」、看见
  32–42¢ 就挂。005 / 006 / 007 / 008 / 014 / 016 的计量部分一字不动。
- 下一步只剩一条: 015 的 **C（贴价挂，赚价差而不是预测方向）**。它是唯一没被这次数据否掉
  的方向，因为它不要求模型比市场准 —— 数据恰恰说明中价是准的，价差才是会付钱的那个量。
  016 给它的前置是 ≥300 小时真 tape + 样本外 `maker_edge_at_fill` 为正、区间不跨 0。
  **后半句作废**，见下。
  **当前归档 92 小时；Kalshi 分钟 K 线只回溯约 4 天，补不出来，只能持续攒。这是现在唯一
  的瓶颈。**
- 连带修正 016: `maker_edge_at_fill = fill_model_p − paid`，`fill_model_p` 就是本决定判死
  的 `digital_prob`。拿它当 C 的判据是循环论证，而且偏差单向：0.55 地板把 p 拽向 0.5，在
  0.25 挂单会成交的便宜那侧模型读数偏**高**。92 小时真 tape 实测（findings 第 7 节）：中价
  0.15–0.20 档 016 口径 **+0.023（通过）**，诚实口径 **−0.082（每张亏 8 分）**；0.20–0.25

  - C 的前置改为: ≥300 小时真 tape + 样本外 **`maker_edge_realized`** 为正、区间不跨 0。
- 不采纳: 尾部保险（0.97–0.99 买近确定的 YES）。24 小时看着每笔 +1~2% 且全胜，样本翻到

### 018 阶梯套利与贴价做市，也在真 tape 上测完了（提案）

- 日期: 2026-09-18
- 状态: **proposed**
- 背景: 017 判掉「模型比市场懂」之后，只剩两条不需要模型的路。两条都在同一批 92 小时真 tape 上测完了（`catalog/research/findings.md`）。
- 结果:
  - **静态套利：没有。** 47293 对近 ATM 组合，费前只有 1 次交叉（1¢），两腿 taker 费约 3¢ 吃光。离套利最近 −0.21¢。扫描器对注入的假交叉能检出，所以 0 是真的 0。
  - **贴价做市：中段亏。** 78192 次成交，1 分钟 markout 合计 −0.0011/张（t=−3.94）。按价格切，**0.15–0.85 中段前后两半各 −0.0035 / −0.0037（t≈−4.6）**；尾部（<0.15、>0.85）两半都是 +0.0008~+0.0017。
  - 口径是上界：忽略排队、忽略成交量，maker 费按 0 算。
- 影响 005 / 014 的事实（不是改门，是记录）: **32–42¢ coupon 带正好落在亏得最狠的中段。** 这不构成自动改门，但任何为 005/014 辩护的论证现在必须先解释这个数。
