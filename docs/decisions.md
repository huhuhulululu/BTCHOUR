### 005 coupon 门（`952cb97`）

- 日期: 2026-08-29
- 状态: accepted
- 决策:
  - 涨 = 3 分钟 `|impulse| ≥ $100` 才挂 YES（28–42¢）
  - 跌 = `impulse < 0` 且 32–42¢ 看见才挂 NO（29¢ 飞刀不接）
  - 静 / 弱阳不挂
  - 成交 / 淡化 / 反手撤仍要同向 `|impulse| ≥ $100` 且 ask 还在 rest
  - rest $0.25；不吃 taker；0.50–0.70 垫档不上
- 理由: 「看见 32–42¢ 就挂」在 `AUG2911` +0 / ATM 0.42 停 34 分钟，`t_wait_stop` −85%。「3 分钟 $100 才挂」又找不到点。两头都不回退。

### 010 用户只跟 CMD 说话；每笔实盘单必须复盘

- 日期: 2026-08-29
- 状态: accepted
- 背景: 用户裁决：以后只跟主控沟通，由 CMD 做角色调用和分工。第一条指令是每一笔实盘单都要仔细分析。
- 决策:
  - 对外频道只有 CMD。专员不对用户直接说话。
  - 每笔 `live_one`（成交或撤单）CMD 必须派 **LEARN**（像不像金带子）和 **RISK**（该不该挂），抽查后用表格复盘。
  - 复盘不是改门许可。改门仍走 LEARN→ADV→用户。
  - 样本：372 撤、373 stop、374 clip。漏复盘 = 违规。

### 011 小时盘阶梯操作权高于 15 分钟研究仓

- 日期: 2026-08-29
- 状态: accepted
- 背景: 用户 13:47 EDT：每个小时那么多盘，不可能机会那么少。本仓库敏锐度 / 实际操作可能性远比另外的仓库（`huhuhulululu/kalshi`，15 分钟盘，结论偏无波动率溢价、坐等）更厉害，要把这个更加提权重视。本小时 `AUG2914` 快照 **188** 档，只做成 1 笔噪声 live（375）。
- 决策:
  - 小时盘整条近 ATM 阶梯（距离 **$600**，活盘 **32–42¢**）是**工作盘**，不是 15 分钟仓那种「没边就坐着」。
  - **空仓而近 ATM 阶梯活着 = 策略失败**，不是「没机会」。
  - CMD 心跳必须报：整点档数 / `$600` 内 / 32–42¢ 活档。不能只报空仓。
  - 操作强度优先于 15 分钟研究姿态。不把 15m 坐等抄过来。
  - 本小时已 clip **不 hop**（007）。用满阶梯的提案给下一小时。
  - **不因此回退**：看见 32–42¢ 就挂、成交门 0.45、吃 taker、放宽 `p=0.30`、整条 loop 切 live。
- 理由: 一百多档近 ATM 阶梯是本仓库相对 15m 仓的优势。机会少是策略没用上阶梯。
