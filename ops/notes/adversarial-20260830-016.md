# ADV — 016 对抗复核

**攻得倒。**

攻击对象：LEARN-016「可采纳候选」及 ARCH 推荐 C（A：live 成交门；B：改为“正在交易的价”；纸盘先行）。

## 攻击点

1. **样本 = 1，且唯一金带恰是旧语义的反例，不是 B 的证据。** 全史唯一同时满足挂时同向 `|impulse| ≥ $100`、带内、真成交、clip 的 #28（AUG2608），用的正是旧 `rest 0.25 under ask 0.34`，最终 `t_clip +0.4502`。它证明旧 rest 至少能成赢单，直接推翻“排除赢单”的绝对命题；最多只能怀疑旧 rest 有不利选择倾向。反面的 12 次成交又几乎都混有弱动量这个混杂因素，不能把损失单独归因给 rest。AUG2520 手册只给出 0.20–0.29、且“多数挂单”，没有同时盘口，撑不起“就是挂在正在交易的价”这一精确反事实。C 尚无一笔自身样本。

2. **C 把 014 的停机门永久化后，会先挡掉用来证明 B 必要的真 dump，属于来回矫枉过正。** 384 是 NO 0.33→0.94 的真砸盘小时，但最深 3 分钟动量仅 −40.96；386 的真 dump 峰也只有 −68.26，且当时 ask 0.23–0.25、已在 32–42¢ 带外。C 要求“挂时 ≥$100 且带内”，这两例都不会挂，B 的新挂价根本没有执行机会。于是 C 不能声称修复 384/386 暴露的构造，只证明它能挡弱噪声；这与 014 的止血作用相同，不是产出金带能力的证据。014 仍应保持安全停机补丁定性，不能被 C 借壳写成优化。

3. **B 的语义不可执行地含糊，A 也未形成独立保护。** “正在交易的价”究竟是 best bid、best ask、last trade 还是别的价没有定义；买在 best ask 可能被 post-only 拒绝，买在 best bid 又涉及排队，不能等同于“立即按交易价成交”。若 B 确实令成交显著提速，挂门和成交门大概率读取同一笔 ≥$100 tick，A 只是重复检查，来不及识别瞬时尖峰或 fade；若等待后再检查，则完全依赖连续 journal。ARCH 已承认 B 单走会给噪声提速，但尚未证明 C 中的 A 与 B 在时间上可分离，捆绑不自动消除该风险。

4. **A 在停机下空转，而且“成交门”发生在真钱已经成交之后。** `live_one=False` 时交易所 direct-promote 路径不可达，纸盘只能测模拟成交，测不到真实排队、exchange fill、direct-promote 和无效成交后的持仓处理。“否则按无效成交处理”也不完整：交易所一旦成交就已有真实仓位，依据 013 不能靠“不 promote”把仓位当不存在；若需立刻 flatten，还会引入薄盘交叉税。故纸盘先行可以限制暴露，却不能验证 A，更不能把 A+B 都验证过作为 C 的结论。

5. **journal/working-order 断档使成交门虚设，且修 journal 还不等于修订单管理。** 388 的成交落在 77.7s 写侧断档中，随后另有 121.6s 断档；386 即使 journal 在线，动量已淡到 −0.60、ask 出带约 10 分钟，工作单仍未撤，说明还有 `no_coupon` 后不管理 working order 的路径。ARCH 把 ENG 修断档列为前置是对的，但前置尚未完成和实证，不能反过来支撑“推荐 C”。在连续观测、工作单持续管理及真实成交后持仓语义均闭环前，A 只是纸面门。

6. **回放没有给 C 任何支持，单笔纸盘 clip 仍是半样本报喜。** 当前 `flex_skip` 16h/24h 均 0/0/0；`flex_nowait_24h` 的 +1.1704 是 taker 对照，`flex_cheap_24h` 为 −0.8467，LEARN/ARCH 没把它们混进默认，这一项未命中。但回放和纸盘都复现不了 post-only 排队、真实 fill 时点、journal 盲区及 direct-promote。即使以后纸盘只出一笔 AUG2608 型，它也只是 014 的最低重开前置之一，不足以证明 C：没有合格机会分母、噪声成交率、漏掉的 `<$100` 真 dump，以及旧 rest 与 C 同窗对照，仍无法区分语义改善与单次好运。

## 固定清单结论

- `flex_nowait` 混默认、把现有回放绿当达成：**未命中**；两份稿都明确排除了它。
- 半样本报喜、样本 = 1、门来回矫枉过正、B 给噪声提速、A 停机空转、journal 让成交门虚设：**均命中**。
- 0.45 / taker / `p=0.30`、重开 `live_one`：两份稿未建议，**未命中**；不得因此给 C 加证据分。

## 降级建议

将 LEARN-016 与 ARCH C 从“可采纳候选 / 推荐”降级为**待测构造假设**，暂不进 decisions、暂不让 C 纸盘语义生效；014 停机保持不动。重新送 ADV 前至少要有：maker-safe 的 B 精确定义；journal 与 working-order 管理连续性证据；同窗冻结对照的机会分母与结果分布，并单列 384/386 这类 `<$100` 真 dump 漏失。不得用一笔纸盘赢家代替分布证据。
