## 一、先把「优化」钉死：什么不算

- **014 不算优化。** 014 是安全停机补丁（decisions 014 定性原文），「不挂了所以不亏了」是止血，不是打出 clip 的能力有任何提升。停机期间纸盘 0 挂单 = 门在执行，不是变好。
- **放宽门不算优化。** 0.45 成交门 / taker / p=0.30 / 看见 32–42¢ 就挂，全部对照过更亏或吃瘪（008、GOALS「不是目标」表）。连续割肉的病根不是门太紧——382–388 七张全是字面过门的弱跌噪声，门反而是太松（跌侧无幅度下限，014 停机期已临时补 $100）。
- **回放绿不算优化。** 本轮 sweep 现行 `flex_skip` 16h/24h 均 0/0/0；`flex_nowait_24h` 那笔 +1.1704（AUG2911 YES taker）是对照路径不是现行路径，且吃 taker 本身就是禁区。回放窗口里现行门打不出单，优化不可能从回放里长出来。

**什么才算达成**（= 014 重开 live_one 条件①，本轮不新造标准）：纸盘在现行门（含停机期 $100 跌侧挂门）下走出一笔 **AUG2608 型**——挂时同向 |impulse| ≥ $100、32–42¢ 带内、真成交、10–50% clip。出现之前，一切都是候选。

## 四、可证伪优化路径（≤3，含 015）
