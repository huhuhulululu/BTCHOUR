## 五问逐答

### 1. 判决词

**可采纳候选。同时：不是达成。** 三件套是收紧不是放宽（008 无冲突），字面执行用户 07:42「没有新的改善或变化就不要做了」，且金带子样本在三道门下全部存活（见问 2）、噪声家族在挂单侧被全数挡掉（见底稿）。但必须钉死三点：① **停机状态下达成（真单 dump NO clip）不可能发生**——live_one=False 之后 wait_fade 和 $100 成交管理对真单是休眠的，三件套里立即起作用的只有纸盘挂门；重启 live_one 要用户点头。② **回放验证不了这个门**——本轮 sweep 现行 flex_skip 16h/24h 均 0/0/0，回放里根本没有单可以对照；将来纸盘 0 挂单是门在执行，不是变好，也不许写成变好。③ **金带子样本 = 1**（trades#28），这正是 ADV 要攻的（见问 4）。

### 2. $100 挂门杀不杀 AUG2608 / AUG2520

**AUG2608（trades#28）：不杀，三道门全过。** journal 实测：挂单 tick 11:39:40Z 动量 **−225.7**（≥100 过挂门）；成交 11:40:08Z（挂后 28s）动量 **−191.4**（≥100 过成交管理门）；动量衰过 −100 在 11:40:56Z——即 wait_fade 若当时生效，金带子的存活窗是 **76s，成交只用了 28s**，淡化撤也不杀它。

**AUG2520（人手金带子）：不杀，但窗口被压缩，且逐笔不可判。** replay-cache 1 分钟 spot 重算 3 分钟动量：人手交易的前半小时（23:00–23:30Z，收 00:00Z）里 **4 个 tick ≥$100 跌**——23:08（−112）、23:19/23:20/23:21（−119/−161/−146），正好夹着 spot 78945→78642 的两条主砸腿，T78799/T78699/T78599 三笔 NO 进场大概率落在这两腿上。但第二腿衰竭段 23:22–23:27 动量 −55~−91，$100 门是关的——人手当时约 20 分钟的连续负带被压成约 4 分钟。数据限制：1 分钟缓存 + manual.md 无逐笔成交时刻，**只能判「窗口存在」，不能判「每一笔仍在」**。

一个 brief 没写的形态事实（问 4 的根）：**#28 自己最深的 2 分钟也是挡着的**——11:38:00–11:39:29Z 动量 −104→峰 −245.6，journal 全程 `blocked`（T78399 ask 0.49 / T78299 ask 0.46–0.43 出带）；直到 11:39:40 ask 掉进 0.34 才挂上，那时动量已回落到 −226。$100 门留下的唯一可挂形态是「**ask 自上而下穿 0.42→0.32 入带、且动量尚未衰过 100**」。386 那种形态（dump 峰 ask≤rest 0.25，衰竭后 ask 反弹入带）过去接的是衰竭尾（−4.2），新门下连衰竭尾也不接——这是对的，但也意味着可挂形态非常窄。

### 3. 停 live_one 是不是「没有改善就不要做了」

**是，而且是唯一诚实的读法。** 真挂账（本轮复核 CMD 数字全对）：live_one 共 **17 张**（372 wait_wrong_side 撤、376 YES 撤、384 0 成交撤），有交易所成交的 **14 张净 +0.0677**（含 379 reconcile；严格 live_fill≥1 口径 13 张 +0.0809）。这个正数是假的：**全靠 378 的 +0.2325 撑着，而 378 是 flatten 假平仓（013 的案发现场）之后 CMD 人工补平救回来的**；剔除 378，13 张净 **−0.1648**，14 张里 7 输 7 赢掷硬币。挂单侧无一张 NO 在 |impulse|≥$100 时挂出（−0.17 到 −36）；成交侧「成交 ⇔ 方向失败」到 388 已 12 次实证。真 coupon 全家 33 笔 17 胜净 **−7.4377**。没有改善，没有变化，停——同时不是回退成「不挂 YES / 不做」（008 禁的是放宽和回退整个路径）：纸盘继续在新门下攒证据，这是「先停再证」。

### 4. rest 0.25 真 dump 不可挂（386）——不另开，并入 384 题并升级为 014 核心

**不另开新 ADV 题。** 384 立、386/387/388 三次补强的对开题（「rest 0.25 挂单语义 = 只成输单、排除赢单」）还挂着没派（CMD 欠账），386 的「真 dump 峰 −68.3 时 ask 0.23–0.25 ≤ rest、构造性不可挂」是它的子问题。014 把这道题从「噪声过滤」升级成「**存在性**」：$100 门把入场压缩到问 2 那个唯一形态之后，全部历史里过三道门的样本只有 #28 一个。ADV 要攻的对开面：(a) 「深砸时邻档 ask 正好穿带下行 + 动量未衰」的联合事件测度是否为零附近——若是，三件套 = 体面的永久停机；(b) wait_fade 依赖 journal 在线，而 386/387/388 三次写侧断档签名（77.7s/121.6s/131.1s，388 的成交本身就在盲区里）意味着**淡化撤在盲区内跟 005 撤单语义一样不存在**——ENG 断档题不修，wait_fade 是纸面语义；(c) 出场管道（trail/scratch 交叉滑点把 +32% 峰磨成 +0.0062、把 −5.3% 放大成 −28.3%）即使入场修好也兑现不了 10–50% 带。
