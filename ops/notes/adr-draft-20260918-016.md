# ADR 草稿 — 016 — 计量先修好，再谈改门

日期: 2026-09-18
角色: ARCH（草稿）
状态: **草稿**。未生效。改门仍走 ARCH → ADV → CMD → 用户。
前置题面: decisions **015**（挂单语义题，proposed，未决）

## 一句话

015 那道题现在有数了：**不是阈值松紧的问题，是回放先在自己给自己发钱，然后 20% 门又把能成交的单全筛掉了。** 本草稿只主张修计量，不动 005 / 006 / 007 / 008 / 014 任何一条门。

## 证据

全部来自 `python3 -m btchour research`，合成盘，每行 200 小时，表在 [`catalog/research/findings.md`](../../catalog/research/findings.md)。

1. **回放成交模型造假**。`fair` 世界盘口报的就是公允值加价差，谁都不该赚钱。旧成交模型在这里打出 119 笔 / **90% 胜率** / **t = 7.09**。机制：`wait_book_crossed` 用分钟内买一最高点判成交，持仓却按同一分钟收盘标记，等于把一分钟 8–10¢ 的概率摆动白送。本文件上半部分那些 `6/6`、`5/5` 全走这条路。
2. **诚实成交之后不是亏，是不成交**。`close` 成交每小时 **0.02–0.04 笔**，200 小时 4–7 笔。
3. **成交那一刻是负 edge**。付 0.25，公允盘里东西值 0.235（−1.5¢），反应过度的盘里值 0.196（−5.4¢）。在专门为顺动量造的 `underreact` 世界里 edge 是 +0.159 —— 方向对，但一小时 0.02 笔。**机制不是方向错，是被自己饿死。**
4. **20% 门 = 要求比自己的模型便宜 16.7%**。`EV = p/c − 1`，所以 `EV ≥ 0.2 ⟺ c ≤ p/1.2`。25¢ 的票要 5¢ 错价，35¢ 的要 7¢。1¢ 价差的盘口不给这个。
5. **结算模型少算了 TWAP**。60 秒均价只带 `m/3` 秒方差，旧代码反而把 τ 压在整 60 秒。剩 60 秒、$50 实值：p 应是 0.928，旧模型说 0.801。最后 5 分钟 Brier 0.0371 对 0.0380。

## 选项

| | 做什么 | 结果 |
| --- | --- | --- |
| **A** | 维持现状，继续等一次真 dump | 回放和 sweep 的数字不可信，谁也没法证伪任何提案。等于无限期停摆 |
| **B** | **只修计量**：回放成交默认按收盘、结算模型按 TWAP、研究框架 + 真 tape 归档 + 样本外切分。门一字不动 | 推荐。不改任何交易行为，只让后面每一个数字能站住 |
| **C** | 改挂单语义：rest 从「盘口下方 8¢」改成贴价挂（吃价差，不要折扣） | 结构上能解决 015，但**必须先有真 tape 校准**才能判断价差够不够覆盖逆向选择。现在提就是拍脑袋 |
| **D** | 换目标函数：单笔 EV ≥ 20% → 每笔小正 EV × 笔数 + 风险上限 | 方向对（稳定收益本来就靠大数定律），但前提是模型能跑赢市场中价，**这件事在真 tape 上还完全没验证过** |

## 推荐

**现在做 B，只做 B。** C 和 D 写成 017 / 018 提案，前置条件写死：

- 归档里有 **≥ 300 小时**真 tape；
- 在**样本外那一半**上，`maker_edge_at_fill` 为正且 95% 区间不跨 0；
- 模型对真实结算的 Brier 要低于「直接用市场中价」的 Brier —— 跑不赢中价就没有任何 taker 类提案可谈。

## 明确否决（不因本草稿回退）

成交门放到 0.45、吃 0.45–0.70 taker、放宽 `p=0.30`、整条 loop 切 live、回退「不挂 YES」、看见 32–42¢ 就挂。本草稿一条都不碰，也不拿「回放变绿」当达成 —— 恰恰相反，本草稿的主要结论就是**过去那些绿是回放付的钱**。
