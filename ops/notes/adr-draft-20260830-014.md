## 3 推荐：D（降级为「安全停机补丁」），附三条前置 + 一条重开条件

推荐 **D**，但必须连下面这些一起进 decisions，否则 D 会被误读成「策略改好了」。ADV 判**攻得倒**并建议降级，ARCH 接受降级（§3.1）：014 的标题与正文按**停机补丁**写，不按「005 可采纳修订」写。

**前置（定稿前 CMD 必须确认）**

1. **切换前交易所必须零持仓、零 resting。** 因为 §1.2：`live_one=False` 会同时关掉 013 对账。388 已平、无 389，现场大概率干净，但这条要人工确认，不能默认。
2. **对账与开关解耦**列为 ENG 题（下一轮）：对账应按 `can_sign` + sqlite 里还有没有 live_one 行来判，不按 `settings.live_one`。在解耦之前，`BTCHOUR_LIVE_ONE=1` 只能由 CMD 手动重开，不能由 env 顺手打开。
3. **`wait_fade` 现在是休眠路径。** `live_one=False` 时不存在真单 rest，这条分支跑不到。ENG 的绿测是构造出来的，不是真单验证过的。重开 live 前必须重测。

**重开条件（写进 014，避免「停」漂成无限期）**

默认保持 `live_one=False`。同时满足才向**用户**申请重开：

- 纸盘出现 ≥1 笔 AUG2608 型：挂时同向 \|impulse\|≥$100、ask 在带内、真成交、10–50% clip 落袋；
- 015（挂单语义）有 ADV 对开后的结论；
- `wait_fade` 经真单或专测验证（回放不算，见 §3.1）。

## 5 后果

**5.1 会发生的**

- 真单归零，010 复盘暂时无新样本；证据只能来自纸盘。CMD 心跳仍要按 011 报整点档 / $600 内 / 32–42¢ 活档，**不能因为停真单就退回「没机会」的播报**。
- 跌侧纸盘挂单频率大幅下降。−15 到 −0.2 这一档全部挡掉；384（−41）、386（−68.3）这种真砸盘小时**也挡掉**，因为都没到 $100。
- AUG2608（挂 −226 / 成交 −191 / `t_clip` +0.4502）仍过门——这是 D 的下限保证。

**5.2 必须对用户说清的**

$100 挂门 ∩ 32–42¢ 带 ∩ ask > rest 0.25 三个条件很可能**构造性互斥**：386 的真 dump 峰值 −68.3 时 NO ask 是 0.23–0.25（在带下且不高于 rest），等 ask 涨回带内时动量已衰竭到 −4.2。也就是说，D 之后跌侧大概率**几乎不再挂**。这是可接受的（用户说的就是「没有改善就不要做了」），但**不得把「不挂了所以不亏了」写成策略改善**。D 是一次有纪律的暂停，不是一次修复。真正的修复候选是 F/015。

**5.3 没有解决的**

- 挂单语义与金带子的构造性错位（384 结论）——留 015。
- 出场侧管道：385/386 同额 +0.0062、388 标记 −5.3% 实收 −28.3%（滑点 6 tick = 本金 24%）——即使挂门修好，这条管道也兑现不了 10–50% 带。留 ENG/015。
- journal 写过滤器（\|impulse\|≥40）造成的复盘盲区——观测缺陷，不是门，留 ENG。撤单看的是 scan 动量，不受影响。

**5.4 文档连带**

- 005 **不改原文**（decisions 头部规则：追加写入，不修改已有条目）。014 作为新条目写「停机补丁」，
  **不写成「005 可采纳修订」**（ADV 降级要求）：$100 只在停机期间约束纸盘挂门，重开 live 时重新论证。
- DOC 已对齐 `catalog/rules/plays.md:12/23`。**`catalog/rules/swing.md:29` 仍是旧句**「跌（impulse<0）且 32–42¢ 看见才挂 NO」，定稿后需补（`ops/notes/doc-20260830-014.md` 第 3 条）。
