## 2. 现行默认 `impulse_wait`：进场公道，**出场在亏钱**

按 005 原文挂：跟带子、同向 `|impulse| ≥ $100`、$600 内、32–42¢ 看见才挂 25¢；
成交要该侧卖一真的打到 rest 且同向动量还在。

| | n | 每张净 | t |
| --- | ---: | ---: | ---: |
| 挂 2389 张，成交 348 张（**14.6%**） | | | |
| 成交 → **持到结算** | 348 | **−0.86¢** | −0.33 |
| 成交 → **现行出场栈**（10–50% 带 / −80% 止 / 8 分钟 scratch） | 348 | **−4.14¢** | **−4.99** |
| 同一信号改吃 32–42¢ 卖一 | 2389 | −3.82¢ | −3.38 |

- 14.6% 的成交率就是 015 的题面被量出来了：rest 0.25 要求市场先给 8¢ 逆向折扣。
- **进场是公道的**（25¢ 买、24.1% 结算、maker 费 0 → −0.86¢，统计上是零）。
- **出场栈每张扣 3.28¢**，t=−4.99。日历前后半都显著（早半 −7.96¢ t=−4.60 / 后半 −3.31¢ t=−3.06）。
- ADR 008「不吃 32–42¢ taker」被一年级样本证实：−3.82¢ t=−3.38。

## 3. 出场栈的代价被第二组数据独立复现

拿完全**同一批**进场（第 4 节那条 cushion 规则）再跑一次：

| 同一批进场 | 每张净 | t |
| --- | ---: | ---: |
| 持到结算 | **+0.53¢** | +0.62 |
| 套 10–50% 带 + 4¢ 回撤 + 止损 | **−1.61¢** | **−4.73** |
| `lock_on_book` 20%（只在锁住 20% 时卖） | +0.59¢ | +0.69 |

赢家被截在 +10%、输家一路亏到底，是不对称截断，不是阈值松紧。`lock_on_book` 无害：它
永远不亏着走，与持有到结算持平。

15 分钟仓在另一套数据、另一个合约上得到同一结论（phase4 G1 十一条出场全负；phase12b
止盈在每一个价带都比持有差 1.3–2.7¢）。三组独立证据同向。

## 判决

1. **66 天里，这条阶梯上没有任何一条能扛住费用的 taker 或 maker 规则。** 阶梯有效；
   便宜侧贵 1–3pp；偏强侧的毛边正好等于二次费。
2. 因此本轮能拿到的 EV 提升是**减法的，而且是可量的**：

   | 动作 | 每张回收 | 证据 |
   | --- | ---: | --- |
   | 成交的 coupon 不再跑出场栈（017） | **+3.28¢** | 第 2 节，两个半样本都显著 |
   | 不吃 0.32–0.42 taker（008 已经如此） | +3.82¢ | 第 2 节 |
   | 不碰 0.18–0.32 便宜侧 | +3.3 到 +4.5¢ | 第 1 节 |

3. `cushion_hold`（016）**不接线**。默认关，留在 `sweep` 当对照，和 `flex_cheap` /
   `flex_nowait` 同一个位置。样本再长一倍之后按同一套脚本重测。
4. **回放变绿不是达成**——反过来也成立：这份表不是「没机会」的许可。它说的是，机会不在
   32–42¢ 的挂等里，而且现行出场栈正在把公道的进场变成亏损。
