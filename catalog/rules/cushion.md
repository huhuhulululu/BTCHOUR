## 一句话

**带子已经把行权价甩开了，盘口还没走完这段路。** 现货离行权价至少 `1.5` 个**剩余波动**
（`sigma_cushion`，`lock_hold` 用的同一个函数，只是门低得多），而那一侧的卖一还在
**$0.70–$0.90**。吃卖一，**持到结算**。

机制借自 `huhuhulululu/kalshi` phase1 的唯一跨币种失效点（偏强 0.85–0.95 被低估 1.5–2pp）。
参数是在 `KXBTCD` 自己的带子上重量的，不是抄那边的 (4, 5, 13)。

| 门 | 默认 | 环境变量 |
| --- | --- | --- |
| 缓冲 | `σ_cushion ≥ 1.5` | `BTCHOUR_CUSHION_MIN` |
| 卖一 | **$0.70–$0.90** | `BTCHOUR_CUSHION_MIN_ASK` / `_MAX_ASK` |
| 方向 | 现货高于行权价买 YES，低于买 NO（只买已经决定的那一边） | — |
| 窗口 | 只做 `KXBTCD` 小时盘，剩余 ≥ **120 秒** | `BTCHOUR_CUSHION_MIN_SECONDS` |
| 张数 | 一小时最多 **3** 档，按缓冲从宽到窄 | `BTCHOUR_CUSHION_MAX_PER_HOUR` |
| 出场 | **结算**。只有 `lock_on_book`（买一已经锁住 20%）能提前走 | — |
| 开关 | **`0`** | `BTCHOUR_CUSHION_HOLD` |

## 为什么不接线

1544 小时 / 66.2 天：

| | n | 校准 | 每张净 | t |
| --- | ---: | ---: | ---: | ---: |
| 全样本 | 1612 | +1.25pp | +0.53¢ | **0.62** |
| 日历 T1 / T2 / T3 | | | −0.08 / −0.62 / **+2.28** | |
| 前半 33 天（σ2.0–2.5 × 0.80–0.90） | 178 | **−3.27pp** | −4.04¢ | −1.39 |
| 后半 33 天（同格） | 255 | **+5.60pp** | +4.83¢ | +2.72 |
| **+1¢ 滑点** | 1612 | +0.25pp | **−0.42¢** | −0.49 |

两个日历半样本符号相反，全样本 CI 含零，一跳滑点翻负。打乱结算的零假设过了（观测 +0.53¢
vs 零假设 95 分位 −33.2¢），所以它不是纯拟合噪声——但「不是噪声」不等于「有边」。

第一次看见它是在 18 天的样本上：**+2.7¢ t=2.2**。样本一长就塌。**小样本变绿不是达成**，
在进场规则上和在回放上一样成立。

**重开条件**：样本 ≥130 天后按 `research/study_rule.py` 原脚本重测，两个日历半样本同号
且 +1¢ 滑点后仍为正。

## 为什么门是 $0.70 而不是 $0.55

回测里 `0.55–0.90` 和 `0.70–0.90` 是同一批单——缓冲到 1.5σ 时盘口几乎不会低于 0.70。取
**0.70** 是为了让 008 的「不吃 0.45–0.70 taker」原文一字不动仍然成立：这条 play
**结构上不可能**落进那条带子。

## 为什么不做T（这一条通过了，见 017）

同一批进场，套上现行 10–50% 带 / 4¢ 回撤 / 止损之后，每张从 **+0.53¢ 变成 −1.61¢
（t=−4.73）**。`impulse_wait` 成交那批是 **−0.86¢ → −4.14¢（t=−4.99）**。两组互不相干的
进场、同一个方向、都显著。赢家被截在 +10%，输家吃满止损——不对称截断，不是阈值松紧。

`lock_on_book` 留着：它只在买一已经锁住 20% 时卖，永远不亏着走，回测里与持有到结算持平
（+0.59¢ vs +0.53¢）。
