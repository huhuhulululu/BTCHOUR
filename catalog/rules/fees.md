# Kalshi 二次费率（KXBTCD）

官方一般 taker 公式（2026-07 费率表，系列乘数 M）：

```
fee = ceil_to_$0.0001(M × 0.07 × C × P × (1 − P))
```

- `P`：成交价（美元，0–1）
- `C`：合约张数
- `M`：`KXBTCD.fee_multiplier = 1`

100 张、M=1 的对照：

| P | 费用 |
| --- | --- |
| 0.10 / 0.90 | $0.63 |
| 0.50 | $1.75 |

Maker 默认乘数为 0（挂单成交常为 0 费率，除非系列被单独标成 maker fee）。本引擎对 maker 按 0 费率估 ROI。提前平仓击买一按 **taker** 再收一次二次费；`lock_exit_price` 已计入这笔卖出费。

20% **若猜对** 的净收益门槛（1 张、M=1）：

- Taker：最高买入价 **$0.82**（0.83 扣费后略低于 20%）
- Maker：最高买入价 **$0.83**
