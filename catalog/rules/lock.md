# 稳健锁仓（默认 playbook = `lock`）

换思路之后，20% 不再靠刮头或 p=95% 的“差不多”。**只有合约已经被价格决定、并且费后猜对还能赚 20%，才进场。**

计分式不变：

```
EV = p · b − (1 − p)
```

在 b≈0.20 时，要 EV≥20% 需要 **p ≥ 0.998**。所以门槛是：

| 门 | 默认 | 为什么 |
| --- | --- | --- |
| 波动缓冲 | **σ ≥ 3.2** | 现货离行权价至少 3.2 个剩余波动，不是贴着行权价赌方向 |
| 胜率 | **p ≥ 99.8%** | 95% 的“便宜 ITM”在回放里会被砸穿 |
| 若猜对 | **b ≥ 20%** | taker 最高买 **$0.82**，挂等 **$0.83** |
| EV | **≥ 20%** | 同一套公式 |

## 怎么成交

1. **`lock_hold`**：盘口已经 ≤ $0.82，IOC 吃掉，拿到结算。
2. **`lock_wait`**：合约已决定但卖一还在 $0.95–$0.99。在 $0.83 **挂等**。纸交易记 `working`，**不成交不算赚**。只有卖一打穿 $0.83 才晋升为开仓。
3. 扫描小时盘 + 当天 5pm + 本周 5pm + **15 分钟涨跌**。窗口越多，越可能等到一次礼品价。
4. 不刮头、默认不提前平。模型跌破门槛就撤挂单。

## 现在盘口通常是什么样

深 ITM 的卖一几乎总是 $0.97–$1.00。最近 8 小时连 K 线最低价也**没有**出现过「σ≥3.2 且 ask≤$0.82」。所以默认行为是：**挂着等，空仓也是正确的。**

这仍不是“每小时保证进账 20%”。稳健的意思是：**宁可零笔，也不再拿会亏光的 95% 票去凑 20%。** 真成交的那一笔，费后猜对应至少 20%。
