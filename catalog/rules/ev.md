# EV = p · b − (1 − p)

这是小时盘的**唯一计分式**。单位是「每一美元本金的期望盈亏」。

| 符号 | 含义 | 本仓库从哪来 |
| --- | --- | --- |
| **p** | 猜对的概率 | BRTI 现货相对行权价的 GBM 数字期权概率 |
| **b** | 净赔率 = 猜对利润 / 本金 | `(1 − 成本) / 成本`，成本 = 买价 + Kalshi 二次费 |
| **1 − p** | 猜错时按本金计的损失（亏光这一美元） | 二元合约猜错结算 $0 |

代数上等于 `(p − 成本) / 成本`，也就是期望 ROI。门槛默认 **EV ≥ 20%**。

## 算例

`p = 0.99`，`b = 0.25`（猜对赚 25%）：

```
EV = 0.99 × 0.25 − (1 − 0.99) = 0.2475 − 0.01 = 0.2375
```

过 20% 门槛。

`p = 0.50`，`b = 1.00`（猜对翻倍）：

```
EV = 0.50 × 1.00 − 0.50 = 0
```

不过。高 b 不能救低 p。

Taker 买在 $0.82（费后成本约 $0.8304）时，`b ≈ 0.204`。要 EV ≥ 20% 需要：

```
p ≥ 1.20 / (1 + b) ≈ 0.996
```

所以 20% EV 比「猜对赚 20%」更严：既要够便宜，也要几乎确定。

## 命令

```bash
python3 -m btchour ev --p 0.99 --b 0.25
```

## 这条门到底在要求什么

把 `b = (1 − c) / c` 代回去（`c` = 含费成本），整条式子塌成一个比值：

```
EV = p·(1 − c)/c − (1 − p) = p/c − 1
```

所以 **EV 是「成本比模型概率低多少」，而且是个相对折扣，不是几分钱**：

```
EV ≥ T   ⟺   c ≤ p / (1 + T)
```

`T = 20%` 就是 **要求盘口比自己的模型便宜 16.7%**：

| 模型 p | 20% 门允许的最高成本 | 需要的绝对便宜 |
| ---: | ---: | ---: |
| 0.30 | 0.250 | 5¢ |
| 0.42 | 0.350 | 7¢ |
| 0.60 | 0.500 | 10¢ |
| 1.00 | **0.833** | 16.7¢ |

最后一行解释了 `lock` 的 $0.82 / $0.83 天花板：`p` 最大就是 1，所以**任何贵过 0.833 的票永远过不了 20% 门**，跟它多确定无关。

这件事要看清楚：一条 1¢ 价差的盘口不会随手给你 5–7¢ 的错价。所以 20% 门筛的不是好单，**是「模型和市场分歧最大的时刻」——而那通常是模型错，不是市场错**。回放 0 笔和实盘 17 张噪声是同一件事的两面。

要的是「高 EV 稳定收益」的话，这里有个取舍必须摆明：单笔 20% 是彩票式的门槛，稳定收益靠的是**每笔小正 EV × 笔数**。改门要走 `docs/decisions.md` 的流程，不在本文件里自作主张。

`python3 -m btchour research` 的三个实验就是用来给这类改动定量的，见 [`research.md`](research.md)。
